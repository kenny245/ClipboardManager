# ClipboardManager — 静默剪贴板管理器

> 轻量、优雅、常驻后台的 Windows 剪贴板增强工具

---

## 产品简介

ClipboardManager 是一款桌面剪贴板历史管理工具，支持**文本**和**图片**的自动记录与快速恢复。程序静默常驻系统托盘，按快捷键即可唤出搜索面板，无需切换窗口即可从历史记录中查找并粘贴之前复制过的内容。

灵感源自 Windows 自带的 `Win + V` 剪贴板历史，但提供了更灵活的自定义能力和更精致的视觉体验。

---

## 核心功能

### 1. 剪贴板历史记录

- 自动捕获每一次复制操作（文本 / 图片）
- 支持截图工具（Win + Shift + S）复制的图片
- 支持浏览器右键"复制图片"、文件管理器 Ctrl+C 复制的图片
- 图片在列表中以缩略图预览，标注尺寸信息
- 默认保存 200 条，可在设置中调整（10 — 10000 条）

### 2. 快速搜索

- 输入关键词即时过滤历史记录
- 文本和图片混合展示，一目了然
- Enter 恢复选中项到剪贴板
- Esc 清空搜索并收起面板

### 3. 全局快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + Shift + V` | 唤出 / 收起搜索面板 |

快捷键在任意应用中全局生效，无需先切换到本程序。

### 4. 下拉动画

展开 / 收起列表时采用平滑缓动动画（280ms），不再是突兀的闪现。

### 5. 设置面板

点击搜索栏底部的 **⚙ 齿轮图标** 打开设置：

| 设置项 | 说明 |
|--------|------|
| 最大储存条数 | 超出上限时自动清除最早的记录（10 — 10000） |
| 储存位置 | 自定义数据存放路径（更改后需重启程序生效） |
| 开机自启动 | 勾选后随 Windows 启动自动运行 |
| 显示关闭按钮 | 勾选后状态栏出现 ✕ 按钮，点击退出程序 |

### 6. 系统托盘

程序常驻系统托盘，右键菜单提供：

- 显示 / 隐藏搜索框
- 清空全部历史
- 开机自启动（勾选）
- 退出

## 使用方法

### 基本流程

1. **启动程序** — 双击 `ClipboardManager.exe`，程序静默启动并驻留系统托盘
2. **正常复制** — 在任意应用中 Ctrl+C 复制文本，或 Win+Shift+S 截图，内容自动记录
3. **唤出面板** — 按下 `Ctrl + Shift + V`，搜索面板从屏幕右下角弹出
4. **查找内容** — 在搜索框输入关键词过滤，或直接浏览列表
5. **恢复内容** — 点击列表项或按 Enter，内容恢复到剪贴板，即可 Ctrl+V 粘贴
6. **收起面板** — 按 Esc 或再次按 `Ctrl + Shift + V`

### 图片操作

- 复制图片后，列表中自动显示缩略图和尺寸信息
- 点击图片项 → 恢复到剪贴板 → 粘贴到目标应用
- 右键图片项 → 可选择"删除"或"恢复到剪贴板"

### 窗口拖拽

搜索栏左侧有 **⠿ 拖拽手柄**，按住可将面板拖动到屏幕任意位置，位置自动记忆。

## 数据存储

| 内容 | 位置 |
|------|------|
| 配置文件 | `%APPDATA%\ClipboardManager\config.json` |
| 窗口位置 | `%APPDATA%\ClipboardManager\window_pos.json` |
| 历史记录 | 数据目录下的 `history.json` |
| 图片文件 | 数据目录下的 `images/` 文件夹 |

默认数据目录为程序所在目录，可在设置中修改。

---

## 技术栈

- **Python 3.14** + **PySide6 (Qt6)** GUI 框架
- **PyInstaller** 打包为单文件 exe
- 全局热键通过 Windows API (`RegisterHotKey`) 注册
- 图片存储为 PNG 格式，缩略图实时缩放渲染

---

## 注意事项

1. **首次运行** 时 Windows SmartScreen 可能拦截，点击"仍要运行"即可
2. **开机自启动** 通过注册表 `HKCU\...\Run` 实现，不含任何后台联网行为
3. **图片存储** 会占用磁盘空间，可在设置中减少最大储存条数来控制
4. 程序**不联网、不上传**任何数据，所有记录保存在本地
